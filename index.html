Features

Everything you need, nothing you don't

A focused, safe, dependency-free arena allocator. Generic over any type. No unsafe, no CGo, no heap tricks.

⚡

Zero-allocation reuse

Alloc many values from one backing buffer. Call Reset to reclaim all of them in one shot — no GC involved.

🔒

Fully type-safe

Generic MemoryArena[T] backed by []T. No unsafe.Pointer, no casts, no surprises. The compiler checks your types.

🧩

Slab allocation

Reserve contiguous regions with AllocSlab and AllocSlabWith. Returned slices are capacity-bounded so appends can't corrupt the arena.

🔁

Pooled arenas

PooledMemoryArena[T] hands each goroutine its own isolated arena via sync.Pool — ideal for HTTP handlers and workers.

🌐

Context & HTTP helpers

Inject and extract arenas from context.Context or *http.Request for clean request-scoped ownership.

⏱

Context-aware allocation

ConcurrentMemoryArena[T] provides cancellation-aware allocation methods so goroutines respect timeouts and deadlines.

🛡

Non-panicking variants

Every allocation has a Try* counterpart that returns (value, bool) instead of panicking on capacity exhaustion.

📊

Capacity introspection

Query Used(), Remaining(), and Cap() at any time — no guessing about what's left in the buffer.

Quick Start

Up and running in seconds

Install the package, create an arena, allocate values, and reset — all in a few lines.

Basic arena

main.go go 
package main

import (
	"fmt"

	"github.com/Protocol-Lattice/memoryArena"
)

func main() {
	arena := memoryArena.NewMemoryArena[int](4)

	first  := arena.Alloc(10)
	second := arena.Alloc(20)

	fmt.Println(*first, *second) // 10 20

	arena.Reset()

	next := arena.Alloc(30)
	fmt.Println(*next) // 30
}

HTTP handler with pooled arena

handler.go go 
var pool = memoryArena.NewPooledMemoryArena[int](256)

func handler(w http.ResponseWriter, r *http.Request) {
	pool.Execute(func(arena *memoryArena.MemoryArena[int]) {
		// each request gets an isolated arena
		ids := arena.AllocSlabWith(1, 2, 3)
		ptr := arena.Alloc(42)

		fmt.Fprintln(w, ids, *ptr)
		// arena auto-resets after Execute returns
	})
}

Slab allocation

slab.go go 
arena := memoryArena.NewMemoryArena[string](8)

// copy values directly into the arena
names := arena.AllocSlabWith("alice", "bob", "carol")
fmt.Println(names) // [alice bob carol]

// reserve an empty slab and fill it yourself
slab := arena.AllocSlab(4)
slab[0] = "dave"
// cap(slab) == len(slab) — safe to append to
try_alloc.go go 
arena := memoryArena.NewMemoryArena[int](2)

// non-panicking variant
ptr, ok := arena.TryAlloc(10)
if !ok {
	log.Println("arena full")
	return
}

slab, ok := arena.TryAllocSlab(4)
if !ok {
	// slab does not fit — offset unchanged
	return
}
_, _ = ptr, slab
Arena Types

Pick the right arena for the job

Three complementary types cover every concurrency model — from single-threaded hot paths to high-throughput servers.

MemoryArena[T]

Single-owner

No synchronization overhead. The fastest option for loops, parsers, and any single-goroutine hot path.

no locks
ConcurrentMemoryArena[T]

Shared arena

A semaphore gate serializes all allocation and reset calls. Context-aware methods let goroutines respect timeouts.

semaphore gate
PooledMemoryArena[T]

Per-task isolation

Each Execute call checks out its own arena from a sync.Pool. Zero contention across goroutines.

sync.Pool

Context-aware concurrent allocation

concurrent.go go 
arena := memoryArena.NewConcurrentMemoryArena[int](1024)

ctx, cancel := context.WithTimeout(context.Background(), 50*time.Millisecond)
defer cancel()

ptr, err := arena.AllocContext(ctx, 42)
if err != nil {
	// context cancelled or timed out while waiting for the gate
	return err
}

slab, err := arena.AllocSlabContext(ctx, 4)
if err != nil { return err }

_, _ = ptr, slab

API Reference

Complete API

Every exported function and method. All allocation paths have a panicking and a Try* non-panicking variant.

MemoryArena[T]

NewMemoryArena[T any](size uint) *MemoryArena[T]

Creates a fixed-size arena that holds up to size values of type T.

(arena *MemoryArena[T]) Alloc(obj T) *T

Copies obj into the next free slot and returns a pointer to it. Panics if full.

(arena *MemoryArena[T]) TryAlloc(obj T) (*T, bool)

Like Alloc but returns nil, false instead of panicking. Does not advance the offset on failure.

(arena *MemoryArena[T]) AllocSlab(size uint) []T

Reserves size contiguous slots and returns a capacity-bounded slice. Panics if the slab doesn't fit.

(arena *MemoryArena[T]) TryAllocSlab(size uint) ([]T, bool)

Non-panicking slab allocation. Returns nil, false if the slab doesn't fit.

(arena *MemoryArena[T]) AllocSlabWith(values ...T) []T

Reserves a slab, copies values into it, and returns it. Panics if values don't fit.

(arena *MemoryArena[T]) TryAllocSlabWith(values ...T) ([]T, bool)

Non-panicking copy-in slab allocation.

(arena *MemoryArena[T]) Reset()

Clears the allocated region and resets the offset to zero. Old pointers become invalid.

(arena *MemoryArena[T]) Used() uint  ·  Remaining() uint  ·  Cap() uint

Capacity introspection helpers.

ConcurrentMemoryArena[T]

NewConcurrentMemoryArena[T any](size uint) *ConcurrentMemoryArena[T]

Creates a synchronized arena backed by a single semaphore gate.

Alloc  ·  AllocSlab  ·  AllocSlabWith  ·  Reset

Synchronize access before delegating to the underlying arena. Same signatures as MemoryArena[T].

AllocContext(ctx context.Context, obj T) (*T, error)

Acquires the gate using ctx, then allocates one value. Returns error if context is cancelled.

AllocSlabContext  ·  AllocSlabWithContext  ·  ResetContext

Context-aware variants of slab allocation and reset.

PooledMemoryArena[T]

NewPooledMemoryArena[T any](arenaSize uint) *PooledMemoryArena[T]

Creates a pool of reusable arenas, each of size arenaSize.

(pool *PooledMemoryArena[T]) Execute(action func(*MemoryArena[T]))

Checks out an arena, runs action, resets the arena, and returns it to the pool. Panic-safe reset.

Context & HTTP helpers

Inject[T any](ctx context.Context, arena *MemoryArena[T]) context.Context

Attaches the arena to a child context.

Extract[T any](ctx context.Context) (*MemoryArena[T], error)

Extracts a typed arena from context. Returns ErrNoArena if absent or type-mismatched.

InjectRequest[T any](r *http.Request, arena *MemoryArena[T]) *http.Request

Returns a cloned request with the arena in its context. Does not mutate the original.

ExtractRequest[T any](r *http.Request) (*MemoryArena[T], error)

Extracts a typed arena from the request context.

Safety

Rules to live by

The arena is intentionally minimal. A few invariants keep it safe and predictable.

⚠ MemoryArena[T] is not thread-safe. Use ConcurrentMemoryArena[T] or PooledMemoryArena[T] for concurrent workloads.
⚠ Do not use pointers or slabs after Reset. They still point into the buffer but their values are cleared.
⚠ Do not let values escape a PooledMemoryArena.Execute closure. The arena resets when the closure returns.
⚠ AllocSlab returns capacity-bounded slices. Appending is safe, but values live in the arena buffer.
⚠ ConcurrentMemoryArena[T] synchronizes allocation and reset, not later reads or writes through returned pointers.
⚠ Arena capacity is fixed. Size your arena based on worst-case usage to avoid panics or Try* failures.
